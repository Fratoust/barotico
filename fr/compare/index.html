Comparatif

Comment on y vit, chiffres officiels

Chaque pays est comparé à la moyenne de sa propre région, selon la même source (l'UE pour ses membres, l'Afrique subsaharienne pour le Sénégal, etc.). La couleur indique si la valeur est plus ou moins favorable sur cet indicateur ; un mot donne le sens (au-dessus, proche, en dessous) pour les personnes daltoniennes. Aucune note globale n'est inventée.

Outil avancé

Choisissez d’abord les pays à comparer

Sélectionnez de 2 à 5 pays, puis les indicateurs à afficher. Les mêmes sources valent pour tous les pays.
